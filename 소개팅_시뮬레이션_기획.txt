연애 시뮬레이션 기획

- 입력값 : 플레이어 이름, 나이: 받아서 연상 +4, 연하 -4, 난이도 조절용 옷선택 (상,중,하)

- 시나리오 기획 : 스테이지 3개 / 스테이지별 질문 5개 (단, 스테이지 2,3 은 답변에 따른 질문 분기 3 곱하기 5) (또, 스테이지 2에 깜짝 이벤트 발생 - 시나리오 짤 때 넣어주세요)
			질문별 답변 3개 (호감도 분배 +5, 1 ~ -1, -5) / 스테이지 별 통과 난이도 존재(스테이지 1에서30?, 스테이지 2에서 50?, 스테이지 3에서 70?)
			
- 출력값 : 게임이름 및 줄거리, 상대방 이름 선택(난이도를 은근히 표현하는 이성의 이름), 플레이어 Status, 질문, 답변(보기), 답변 선택 결과, 최종 결과 (스테이지 통과여부, 연애 여부)

+ 시나리오 및 값 추가 안건 : 라이브러리 이용 - 난이도 선택 시 이성 얼굴이미지 띄워주기!, 답변 선택 시 (선택한 답변 + 말투변경 / 상대방 반응 + 속마음 + 호감도 등락 <시스템 표현>)

- 프로그래밍 기획
엔진 & 게임 흐름 담당 (A) : 전체 게임 흐름 제어 (스테이지 진행 및 상태 관리) / 메인 게임 루프 구현 / 각 스테이지로의 분기 처리 / 조건 분기 및 게임 종료 처리 / 파일: Main.java, GameEngine.java

플레이어/상대 상태 관리 담당 (B) : Player 클래스: 이름, 나이, 옷 선택 등 입력값 관리 / Partner 클래스: 상대 정보 및 반응 처리 / 호감도 계산, 상태 출력 로직 구현 / 파일: Player.java, Partner.java, StatusPrinter.java

Stage 1 구현 담당 (C) : 스테이지 1 질문 5개 및 선택지 3개 구현 / 선택에 따른 호감도 등락 처리 / 스테이지 1 통과 기준 적용 / 파일: Stage1.java

Stage 2 + 이벤트 담당 (D) : 스테이지 2 질문 분기 처리 (답변에 따른 다음 질문 변화) / 깜짝 이벤트 로직 구현 (조건/랜덤 발생) / 이벤트에 따른 호감도/상태 변화 처리 / 파일: Stage2.java, EventManager.java

Stage 3 + 멀티 엔딩 담당 (E) : 스테이지 3 분기형 질문 구현 / 엔딩 조건 로직 구현 (연애 성공/실패/보류 등) / 최종 결과 출력 처리 / 파일: Stage3.java, EndingManager.java

입출력 + 유틸 + 이미지 처리 담당 (F) : 사용자 입력 처리 및 유효성 검사 / 공통 출력 UI 유틸 (선택지, 반응, 속마음 등 출력) / 이성 이미지 출력 (난이도에 따라 다른 이미지) / 선택한 답변 말투 출력, 반응 효과 구현 / 파일: InputUtil.java, OutputUtil.java, ImageDisplayer.java

+ 추가 사항 : 데이터 베이스에 플레이어 이름 별 난이도(상대 이성이름(상중하)), 게임 진행 정도(ex. 스테이지2 - 3/5 (60%로 표시?)(이 부분 구현가능한지 모름), 게임 한번 한 기록 저장(배드엔딩-난이도,실패시점,호감도 변화를 나타내주면 멋있을듯! or 해피엔딩-난이도,최종호감도,호감도변화)
